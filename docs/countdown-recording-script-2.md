# Countdown recording — session 2 (lines & cheeky)

Session 1 (numbers 1-31, units, today/tomorrow) is **done and banked**. This
session adds phrasing variety and the repeat-tap jokes.

**23 lines, one take, read in order.** Same rules as before:

- **One continuous take** - export the whole timeline, don't export per line.
- **Pause ~1 second between lines.** Clean gaps = automatic splitting.
- **Flat, even delivery** for lead-ins and trailers (they get glued to a number,
  so no swooping down at the end). The **cheeky** ones are the exception - those
  play alone, so give them personality.
- **22050 Hz, mono, 16-bit.** Same as the existing bank. Don't switch to 16k -
  mixing rates causes a retune click mid-sentence.
- Fluffed one? Pause, say it again, carry on. Keep the order.

---

## Read in this order

### Lead-ins (6) — these run straight into a number, keep them flat
```
1.  just
2.  only
3.  we're down to
4.  that's
5.  guess what
6.  oh boy
```
> Reads as: *"Just twenty three days to go!"* · *"Guess what — four days!"*

### Trailers (6) — these follow the unit word
```
7.  and counting
8.  until we're there
9.  until the castle
10. until we see the fireworks
11. so get packing
12. I can't wait
```
> Reads as: *"Twelve days and counting"* · *"Three days, so get packing!"*

### Cheeky repeat-tap lines (8) — play these with personality
```
13. Again?
14. Still the same number!
15. It hasn't changed since last time.
16. Tapping more won't make it sooner.
17. Okay, okay - I heard you the first time.
18. You really want to go, don't you?
19. Patience! The mouse isn't going anywhere.
20. Save some magic for later!
```
> These fire on the **3rd consecutive tap of the same band**, instead of the
> countdown. They'll be the most-heard lines in the device once someone works out
> they exist - warm and playful beats snarky.

### Milestone lines (3, optional) — replace the trailer on the big days
```
21. One week! Start packing!
22. One month to go!
23. It's almost here!
```

---

## After recording

1. Save the take over `assets\countdown-split\source.wav`
2. Open the splitter, pick preset **"Session 2 - lines & cheeky"**,
   hit **Auto-label in order**
3. Expect **23 segments** (more if you re-took a line - blank the bad ones)
4. **Generate**, run the script -> `named\*.wav`

The new files slot straight into the existing pools (`lead-5`+, `tail-7`+,
`cheeky-1`+) and the composer picks them up with no firmware change.
